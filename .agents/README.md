# Project ECC Skills

This directory contains the project-level ECC skill inventory for Codex.

Most skills were copied from the local user-level ECC install at initialization time so Codex can discover them from `.agents/skills/` when working in this repository.

If user-level ECC is updated later, resync these skills intentionally instead of editing generated copies piecemeal.

The `claude-api` skill was listed in the upstream project inventory but was not present in the local ECC install used for initialization; see `.agents/skills/claude-api/SKILL.md`.
