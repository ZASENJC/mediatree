# 常见问题

## 为什么扫描后没有海报？

先确认媒体库启用了合适的刮削器，并检查 `TMDB_ACCESS_TOKEN` 是否可用。没有 TMDB 凭据时，MediaTree 仍能扫描和播放文件，但电影、剧集海报和详情会明显减少。

## Javdatabase 为什么不在自动刮削里？

Javdatabase 基于番号和站点内容，匹配语义和普通电影、剧集不同。为了避免噪声结果污染普通媒体库，它需要在对应媒体库中单独选择。

## `sp` 文件夹是什么？

影片目录下的 `sp` 用作花絮或特别内容目录。MediaTree 会把它作为文件夹级 specials 处理，避免混入普通列表、继续观看和正片播放队列。

## 为什么有些版本提示完整镜像更新？

这说明运行环境层发生变化，例如 Python、ffmpeg、字体或启动流程。此时只替换应用包不够安全，需要在宿主机执行 `docker compose pull && docker compose up -d`。

## 是否必须挂载 Docker socket？

不必须。普通应用包更新不需要 Docker socket。只有想让设置页执行完整镜像更新时才需要挂载 `/var/run/docker.sock`，但这会给容器宿主机 Docker 控制权。

## 可以不用认证吗？

MediaTree 支持首次设置管理员账号，也支持通过环境变量预置账号。实际部署尤其是公网访问时，应启用认证、使用强密码，并优先放在 HTTPS 反向代理后。
