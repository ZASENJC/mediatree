# 刮削器系统

MediaTree 使用插件化刮削器从多个来源获取标题、海报、演员、简介、季集和图片。每个媒体库可以选择不同刮削器。

## 内置刮削器

### TMDB

`tmdb_movie` 和 `tmdb_tv` 适合电影和电视剧，支持标题、简介、类型、演员、人物、海报、背景图、季海报、分集剧照、预告片、评论和上映信息。

使用 TMDB 需要 `TMDB_ACCESS_TOKEN` 或 `TMDB_API_KEY`。

### Bangumi

`bangumi` 适合动漫和东亚媒体，能获取多语言标题、人物、封面和条目类型。Bangumi 使用公开 API，不需要 API key。

### Javdatabase

`javdatabase` 基于番号匹配 JAV 元数据，包含标题、演员、导演、制作商、厂牌、类型、评分、缩略图和发行信息。它不会进入 `auto` 自动链，需要在对应媒体库单独选择。

### Auto

`auto` 是默认回退链：

1. 尝试从文件名提取 TMDB ID。
2. 有 TMDB ID 时精确匹配。
3. 没有 TMDB ID 时搜索 TMDB 电影和电视剧。
4. TMDB 失败后尝试 Bangumi。
5. 全部失败时保留本地文件名。

### None

`none` 禁用网络刮削，适合只想基于文件名或本地信息展示的库。

## 缓存和刷新策略

- 搜索和详情响应缓存在 SQLite 中，用来减少后台重复请求。
- TMDB/Bangumi 缓存 168 小时，Javdatabase 缓存 24 小时。
- 空结果不会写入缓存，历史空缓存被读取时会自动删除。
- 启动扫描和文件监控触发的自动扫描会使用缓存。
- 手动全量扫描、右键重新刮削、手动刮削和手动应用结果会绕过缓存。

## 手动刮削流程

1. 在文件夹或影片上打开操作菜单。
2. 选择手动刮削或重新刮削。
3. 输入标题、番号或 TMDB ID 搜索。
4. 从候选结果中选择正确条目。
5. 点击应用后写入本地数据库和封面缓存。

## 添加自定义刮削器

开发者可以在 `backend/app/scrapers/` 中新增刮削器，继承 `BaseScraper`，实现 `search()` 和 `get_detail()`，再在 `registry.py` 注册。更多工程细节见[开发指南](/development/)。
