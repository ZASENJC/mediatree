# FAQ

## スキャン後にポスターが表示されないのはなぜですか？

ライブラリが正しいスクレイパーを使っているか、`TMDB_ACCESS_TOKEN` が有効か確認してください。TMDB 認証情報がなくても MediaTree はスキャンと再生ができますが、映画や TV のメタデータは制限されます。

## Javdatabase が自動スクレイピングに含まれないのはなぜですか？

Javdatabase はコードベースで照合し、通常の映画や TV のマッチングとは挙動が異なります。通常ライブラリで不要な結果を避けるため、対象ライブラリで明示的に選択します。

## `sp` フォルダとは何ですか？

作品ディレクトリ内の `sp` フォルダは特典映像や extras として扱われます。specials 専用の表示でない限り、MediaTree は通常一覧、続きから見る、メインのエピソードキューからそれらのファイルを除外します。

## 一部バージョンで完全イメージ更新が必要なのはなぜですか？

Python、ffmpeg、フォント、起動処理などの実行環境レイヤーが変わったためです。ホスト上で `docker compose pull && docker compose up -d` を実行してイメージを差し替えてください。

## Docker socket をマウントする必要はありますか？

通常は不要です。通常のアプリパッケージ更新には必要ありません。Settings から完全イメージ更新を実行したい場合、かつホスト Docker の制御境界を理解して受け入れる場合だけ `/var/run/docker.sock` をマウントしてください。

## 認証を無効化できますか？

MediaTree は初回管理者セットアップと環境変数による認証情報に対応しています。実運用、特に LAN 外からアクセスする場合は、認証を有効にし、強いパスワードを使い、リバースプロキシ配下で HTTPS を使うことを推奨します。
